# AI-Driven Customer Segmentation & Route Optimization

This project demonstrates practical applications of Unsupervised and Reinforcement Learning.
It uses K-Means Clustering to segment customers based on spending and app engagement.
Customer groups are analyzed to identify premium, medium-value, and low-engagement users.
The project also introduces Reinforcement Learning through a delivery route example.
Different routes are evaluated using reward values to identify the best-performing route.
Python, Pandas, Matplotlib, and Scikit-learn are used for implementation.
The project highlights AI-based marketing and operational decision-making.
It provides industry-relevant insights for customer targeting and route optimization.
This practical work was developed using Google Colab/Jupyter Notebook.
